# AchriDZ – سوق المستعمل في الجزائر (Marketplace 69 Wilayas) 🇩🇿

منصة جزائرية متكاملة لبيع وشراء المنتجات المستعملة عبر **69 ولاية جزائرية**، مع نظام إعلانات مدفوعة برسوم نشر ثابتة وإلزامية **200 دج** ونظام مساومة على السعر ودردشة داخلية فورية.

---

## المبدأ الأساسي للمنصة (Règle d’Or)
> **«لا إعلان منشور بدون دفع رسوم النشر 200 دج والتحقق من العملية.»**

- كل إعلان يُنشأ يبدأ في حالة `PAYMENT_REQUIRED`.
- رسوم النشر: **200 DZD ثابتة وإلزامية** يتم تحويلها إلى حساب بريد الجزائر **CCP** أو تطبيق **BaridiMob**.
- لا يتم طلب كلمة المرور الخاصة بحساب CCP أو رمز البطاقة الذهبية أو بريدي موب إطلاقًا (حماية ضد التصيد).
- يراجع المشرف الإيصال ورقم العملية (Référence) ويقوم بـ:
  - **Valider le paiement**: يصبح الإعلان `PUBLISHED` ويظهر للعامة ويصل إشعار للمعلن.
  - **Refuser**: يصبح الإعلان `REJECTED` ويصل إشعار للمعلن لإعادة إرسال إثبات الدفع.

---

## 🌟 ميزات المنصة (الخيار أ)

1. **دعم 69 ولاية جزائرية كاملة (`01` أدرار → `69` دبدو)**
   - فلاتر وبحث مخصص حسب الولاية، البلدية، الفئة، حالة المنتج، والسعر.
2. **نظام حسابات التجريب (Compte Démo Sandbox)**
   - يسمح للمستخدمين بتجريب جميع ميزات المنصة (المراحل العشر لإنشاء الإعلان، وصل الدفع 200 دج الرمزي، المساومة والدردشة).
   - إعلانات الحسابات التجريبية تُوسم بشارة **«إعلان تجريبي (للتجريب لا غير)»** ولا تُنشر فعليًا في السوق العام للحفاظ على جودة الإعلانات الحقيقية.
3. **نظام المساومة والتفاوض المالي (Négociation des prix)**
   - يمكن للمشتري تقديم عرض شراء مالي على السعر المعروض (دج) ويستطيع البائع **قبول**، **رفض**، أو **إرسال عرض مضاد**.
4. **لوحة إدارة متكاملة (`/admin/payments`)**
   - مؤشر إيرادات رسوم النشر: **«Revenus des frais de publication»** (`عدد المدفوعات المقبولة × 200 دج`).
   - إمكانية تعديل بيانات صاحب الحساب البنكي CCP و Clé و RIB BaridiMob مباشرة من لوحة الإدارة.
5. **دعم ثنائي اللغة كامل**
   - العربية (RTL) والفرنسية (LTR) مع تبديل فوري.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد قاعدة البيانات ودفـع الجداول (PostgreSQL)
npx drizzle-kit push

# 3. تشغيل خادم التطوير
npm run dev
```

## 📱 إعدادات التغليف على Android و iOS (Capacitor)
التطبيق مبني بتصميم Mobile-First وبشريط تنقل سفلي (Bottom Dock) متجاوب:
```bash
npm install @capacitor/core @capacitor/cli
npx cap init AchriDZ com.achridz.marketplace
npx cap add android
npx cap add ios
npx cap sync
```
